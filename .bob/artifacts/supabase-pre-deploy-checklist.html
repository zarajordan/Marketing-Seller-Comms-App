🔴 Required — New column added this session
Required Add reviewer_note column

Added for the Return to Sender feature. Stores the reviewer's message back to the event submitter. Without this column, returning an event will throw a Supabase error.

ALTER TABLE events
  ADD COLUMN IF NOT EXISTS reviewer_note text;

Verify Check all recent columns exist

Run this to see which columns are present on the events table:

FROM   information_schema.columns
WHERE  table_name = 'events'
  AND  column_name IN (
         'invite_process',
         'promote_our_presence',
         'promote_documents',
         'reviewer_note'
       )
ORDER BY column_name;

You should see 4 rows. If any are missing, run the relevant statement below:

🟡 Verify — status column values
Verify Confirm status accepts 'Returned'

The Return to Sender feature sets status = 'Returned'. If your status column has a CHECK constraint or enum type limiting allowed values, you must add 'Returned' to it.

Check whether a constraint exists:

SELECT constraint_name, check_clause
FROM   information_schema.check_constraints
WHERE  constraint_name LIKE '%events%status%'
    OR check_clause     LIKE '%status%';

If a constraint is returned and 'Returned' is not listed, drop and recreate it — or if it's a plain text column with no constraint, you're already fine.
